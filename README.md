# 테트리스를 플레이하는 AI입니다.

!!노트북 실행을 권장하지 않습니다!!


상태 평가 변수:
height: 모든 열의 높이 합

danger: 높이의 제곱합 (높이가 높아질수록 기하급수적으로 감점)

center / edge: 중앙 및 가장자리에 뚫린 구멍(Hole) 개수

bumpiness: 열과 열 사이의 높이 차이(울퉁불퉁한 정도)


(best_move): 현재 떨어지는 블록을 4방향 회전시키고 가로 모든 위치에 놓아보는 가상 시뮬레이션을 진행합니다. 그중 점수(evaluate)가 가장 높은 회전수와 X 위치를 찾아 선택합니다.

(learn, learn_gameover): 줄을 지우면 보상을 주고, 높이가 높아지거나 게임 오버가 되면 패널티를 부여하여 내부 가중치(w_height_penalty, w_center_hole 등)를 조금씩 업데이트(경사하강법 방식)합니다.
